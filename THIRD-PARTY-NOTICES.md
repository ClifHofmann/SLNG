# Third-party notices

The canonical notice file is **[`app/THIRD-PARTY-NOTICES.md`](app/THIRD-PARTY-NOTICES.md)**.

It lives inside the Godot project directory deliberately: the Creative Commons licence covering
the Second Life viewer artwork we ship requires the notice to be distributed *with the program*,
so it has to be inside `app/` to be included in an export and readable by the client itself
(Preferences → Licences). This file is a pointer so the notice is still discoverable from the
repository root; do not duplicate the content here.
