# v0.27.0-alpha — Persistent Teleport Avatars, Multi-Threaded Mesh Prep, Interactive Chat Links & Conference Lists

Since v0.26.102, teleports preserve your avatar, worn attachments, and HUDs without reloading; the rendering pipeline prepares meshes, rigs, and collision pick hulls across background worker threads with an on-disk decoded-texture cache; communication gains rich clickable links, @mentions, emoji picker, conference participant panels, and real-time IM typing indicators; and network bandwidth settings now match modern reference viewer standards.

## World & Teleport Persistence

- **Seamless Teleports (FEAT-NET-06):** Your own avatar, worn attachments, and active HUDs are retained across teleports rather than de-rezzing and re-fetching on sim arrival, eliminating teleport hitching and naked reloads.
- **Reference Viewer Bandwidth (FEAT-NET-05):** Added high-bandwidth settings (up to 10,000 kbps) with matching throttling logic to saturate modern connections.

## Performance & Rendering Pipeline

- **Worker-Threaded Mesh & Rig Preparation (BUG-PERF-06, BUG-PERF-08):** Object meshes, HUD geometries, and worn rigged meshes prepare their visual and collision representations on background worker threads. Pick collision hulls are built in chunked slices to prevent main thread hitches.
- **Off-Thread Alpha Classification (BUG-PERF-07):** Avatar face alpha modes are inspected and classified from worker-measured pixel samples without triggering GPU pipeline stalls.
- **VRAM Budget & Adaptive Texture Admission (BUG-PERF-09):** Texture sharpen admissions are budgeted against projected GPU memory usage with graceful fallback.
- **Decoded Texture Disk Cache (FEAT-PERF-11):** Decoded textures are persisted in a binary `.tcache` disk store, significantly accelerating scene pop-in across sessions.

## Communication & UI Enhancements

- **Interactive Chat Formatting & Mentions (FEAT-UI-70):** Chat logs now recognize clickable web URLs, SLurls, and avatar profile links. Type `@` for avatar mention autocomplete, or open the emoji picker dialog.
- **Conference Participant List (FEAT-UI-71):** Multi-party conferences display an active participant list showing members, online profiles, and direct message shortcuts.
- **Reliable Conference Messaging (BUG-NET-32):** Conference group chat delivery and session invitations are reliably routed and acknowledged.
- **Typing Indicator & Tab Awakening (BUG-UI-36):** Incoming IM typing notifications automatically open the peer's tab, unminimize the chat window, and bring it to front.
- **Chat Layout & Landmark Search (BUG-UI-35):** Chat log containers expand horizontally to fill available window width. Landmark search window autofocuses on open and expands matching folders.
