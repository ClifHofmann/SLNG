# v0.27.19-alpha — Worn Animesh Support, Warm-Start & Region Load Performance, and Non-Intrusive IM Typing

Since v0.27.0-alpha, this release introduces full worn animesh attachment support with dedicated control skeletons, massive region load and warm start performance optimizations, and refined communication window focus handling.

## Avatar & Rendering

- **Worn Animesh Support (BUG-AVATAR-10):** Worn animesh attachments now instantiate dedicated control avatars with accurate LLQuaternion attachment point orientations, properly isolating the wearer's Bento skeleton while animating worn attachments.
- **Crowded Avatar Loading & Rig Optimization (BUG-PERF-12):** Completely invisible rigged submeshes are filtered out prior to mesh creation, and rig preparation runs via a prioritized worker pool focusing on nearest avatars first.

## Performance & Region Loading

- **Warm-Start Acceleration (BUG-PERF-10):** Synchronous asset and texture fetches now dispatch immediately to background thread pool lanes, and local agent lookups use validated cached indexing, eliminating main-thread freezes on warm starts with populated disk caches.
- **Budgeted Collision & Cull Sweeps (BUG-PERF-11):** Urgent collision hull creation is budgeted per frame and sorted nearest-first; cull sweep slices are bounded to 4 ms, and collision shapes are reused across LOD ladders.

## UI & Communication

- **Non-Intrusive Typing Indicators (BUG-UI-38):** Incoming peer typing notifications create the conversation tab with an indicator in the background without pulling the user away from active groups, friends lists, or ongoing chats. The window only pops up when previously closed.
- **Foreign Session Routing Diagnostics (BUG-UI-37):** Added routing diagnostics and handling for instant messages belonging to unknown foreign or ad-hoc sessions.
- **Log Hygiene & Release Output (BUG-DEV-01):** Exported release builds now flush stdout immediately on every line, and smoke tests isolate their logs from user session data.
