# v0.26.102-alpha — Landmark favorites and folder management, friend status in main chat, and UI window fixes

Since v0.26.77, landmarks feature a dedicated favorites bar, hierarchical folder tree management, drag-and-drop reorganization, and duplication cleanup; friend log-in and log-out presence can be displayed directly in main chat; and several window clamping and profile bugs are resolved.

## Landmarks and Favorites

- **Favorites Bar:** A quick-access favorites bar sits under the top menu for one-click teleporting to favorite landmarks. Favorites are saved per user and per grid account.
- **Hierarchical Landmark Folders:** The Landmarks window now renders full folder hierarchies. You can create folders, view subfolder contents, and move landmarks across folders.
- **Drag-and-Drop & Move Window:** Drag landmarks onto folders or use the Move dialog to organize landmarks seamlessly.
- **Deduplication:** A dedicated landmark dedup tool identifies duplicate landmarks and recommends keeping the newest version.
- **Keyboard Shortcut:** `Ctrl+L` toggles the Landmarks window, matching Second Life viewer conventions.
- **Tree Hover Fix:** Hovering over folders no longer unexpectedly auto-expands trees in Landmark or Inventory panels.

## Communication & Profiles

- **Friend Status in Main Chat:** Online and offline friend notifications appear in the main chat log (enabled by default, configurable in Preferences → Display).
- **Profile & IM from Chat:** Clicking on avatar names in chat properly resolves their name and loads previous IM conversation history.
- **Display Names in Radar:** The radar list shows avatars' modern Display Names.
- **Group Info & Notices:** Profile flags and group lists reliably update on login and tab selection.

## Windows & Navigation

- **Window Top Inset Clamping:** All floating windows respect the top menu and favorites bar inset on spawn and drag, preventing windows from hiding beneath the top bars.
- **Camera Zoom:** Camera look-at point remains steady on avatar during wheel zoom.

## Verification
